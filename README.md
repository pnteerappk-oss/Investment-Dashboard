# Investment Monitor Dashboard

เว็บแดชบอร์ดสำหรับติดตามพอร์ตการลงทุนส่วนตัว รองรับการดูภาพรวมมูลค่าพอร์ต กำไร/ขาดทุน เงินปันผล สัดส่วนสินทรัพย์ ประวัติการลงทุนรายปี รวมถึงรายการซื้อขาย BTC และทอง

โปรเจกต์นี้เป็น static website ใช้เพียง HTML, CSS และ JavaScript จึงเปิดใช้งานได้ทันทีจากเบราว์เซอร์ และสามารถ deploy ผ่าน Netlify ได้โดยไม่ต้องมี build step

## ฟีเจอร์หลัก

- สรุปมูลค่าพอร์ต ต้นทุนรวม กำไร/ขาดทุนรวม และผลตอบแทนเป็นเปอร์เซ็นต์ โดยรวมเงินปันผล/ดอกเบี้ยที่ได้รับจริง
- คำนวณเงินปันผลต่อปีและ dividend yield
- แสดงสัดส่วนสินทรัพย์ด้วย donut chart และ legend แยกตามประเภท
- ตารางรายการสินทรัพย์พร้อมตัวกรอง เช่น หุ้น กองทุน เงินสด คริปโต และทอง
- เพิ่ม แก้ไข และลบสินทรัพย์ได้จากหน้าเว็บ
- บันทึกประวัติการลงทุนรายปี พร้อมกราฟการเติบโตของพอร์ต
- บันทึกเงินปันผลและดอกเบี้ยเงินฝาก แยกยอดก่อนภาษี ภาษีหัก ณ ที่จ่าย และยอดรับสุทธิ
- บันทึกรายการซื้อขาย BTC และทอง พร้อมคำนวณต้นทุนเฉลี่ยแบบถ่วงน้ำหนัก
- สำรองข้อมูลเป็นไฟล์ JSON และนำข้อมูลสำรองกลับมาใช้งานได้
- ซิงก์ข้อมูลกับ Google Sheet ผ่าน Google Apps Script ที่ตั้งค่าไว้ใน `app.js`
- เก็บข้อมูลในเบราว์เซอร์ด้วย `localStorage` เพื่อใช้งานต่อได้หลังปิดหน้าเว็บ

## โครงสร้างไฟล์

```text
.
├── index.html       # โครงสร้างหน้าเว็บและแท็บต่าง ๆ
├── styles.css       # สไตล์ของแดชบอร์ด
├── app.js           # logic การคำนวณ การจัดการข้อมูล และการซิงก์
├── netlify.toml     # ตั้งค่า deploy และ security headers สำหรับ Netlify
└── README.md        # เอกสารโปรเจกต์
```

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน local server ถ้าต้องการทดสอบแบบใกล้เคียง production

```bash
npx serve .
```

จากนั้นเข้าใช้งานตาม URL ที่แสดงใน terminal

## การจัดการข้อมูล

ข้อมูลหลักจะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งาน ได้แก่

- รายการสินทรัพย์ในพอร์ต
- ประวัติการลงทุน
- ข้อมูลการลงทุนรายปี
- รายการเงินปันผลและดอกเบี้ยที่ได้รับจริง
- รายการซื้อขาย BTC
- รายการซื้อขายทอง

หากต้องการย้ายเครื่องหรือกันข้อมูลหาย ให้ใช้ปุ่ม `Export Backup` เพื่อดาวน์โหลดไฟล์ JSON และใช้ `Import Backup` เพื่อนำข้อมูลกลับเข้าแดชบอร์ด

## Google Sheet Sync

หน้าเว็บมีปุ่ม `Load Sheet` และ `Save Sheet` สำหรับดึงข้อมูลจาก Google Sheet และบันทึกข้อมูลกลับไปยังชีตผ่าน Google Apps Script

ค่าที่เกี่ยวข้องถูกตั้งไว้ใน `app.js`

- `sheetSyncUrl`
- `sheetSyncToken`

หากนำโปรเจกต์นี้ไปใช้ต่อหรือเผยแพร่แบบ public ควรเปลี่ยน URL และ token เป็นของตัวเอง และหลีกเลี่ยงการเปิดเผย token ที่ใช้กับข้อมูลจริง

## Deploy บน Netlify

โปรเจกต์มีไฟล์ `netlify.toml` เตรียมไว้แล้ว โดยกำหนด publish directory เป็นโฟลเดอร์ปัจจุบัน

```toml
[build]
  publish = "."
```

การ deploy ไม่ต้องตั้งค่า build command เพราะเป็นเว็บ static

## หมายเหตุ

ตัวเลขเริ่มต้นในแดชบอร์ดเป็นข้อมูลตัวอย่างเท่านั้น ไม่ใช่คำแนะนำการลงทุน ผู้ใช้งานควรตรวจสอบข้อมูล ราคา และผลตอบแทนด้วยตนเองก่อนตัดสินใจลงทุน
